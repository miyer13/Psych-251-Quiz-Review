1. p-values

A p-value is the probability of data this extreme or more extreme, computed assuming the null is true. It is a likelihood-like quantity about data given H0, not P(H0 | data) and not an effect size.

Under the null, p is uniform on [0, 1]. So 5% of null experiments give p<.05 no matter the sample size. With a true effect, p-values pile up near 0 (right-skewed); the larger the power, the more piled.

Sketch first: draw two histograms of p (x from 0 to 1): one when there is no effect, one when there is a real effect with about 80% power. Then run it.

Challenges

  • Set d = 0. Change N from 5 to 200. Does the null histogram change? (It should not.)
  • Set d = 0.5 and N = 64. What fraction is below .05? Now N = 10.
  • With the one-experiment button, click 10 times at d = 0.5, N = 20. How wild are individual p-values? (This is the "dance of the p-values".)
What p is not: not P(null true); not "probability the result is due to chance"; not the effect size (tiny effects give tiny p with huge N); p>.05 is not evidence of no effect.

2. Multiplicity

If each of k independent tests has a 5% false-positive rate, the chance that at least one is significant is 1 − (0.95)k. k = 2: 9.8%. k = 20: 64%. The fix (e.g., Bonferroni: use α/k) only works if you know k, which is why transparency about the set of tests matters.

Sketch first: plot P(at least one false positive) against number of tests k from 1 to 60. Where does it cross 50%?
Assumes independent tests. Correlated outcomes inflate less than the curve; still well above 5%.

3. p-hacking

Every analysis choice that depends on the data adds a chance to get p<.05 when nothing is going on. Three classic forms: optional stopping (peek, add participants, peek again), selective reporting of outcomes (measure several DVs, report the one that worked), and flexible exclusions/subgroups (try cuts until something is significant).

Why each test being "valid" doesn't help: the guarantee of 5% applies to a single pre-specified test. Stopping at the first success turns many tests into one reported test. Preregistration fixes the stopping rule, outcome, exclusions and analysis in advance, so the number of tests is known and the p-values mean what they claim. Alternatives: sequential designs with corrected α, or Bayesian sequential designs.

Predict: if you test after every 5 participants per group up to 100 per group and stop when p<.05, what is the true false-positive rate? 6%? 10%? 25%?
In every mode the true effect is exactly zero, so every "success" is a false positive. Left: false-positive rate with an honest single test vs the hacked procedure. Right: p-value trajectory of one null experiment as participants accumulate (stopping mode).

4. Statistical power

Power = P(reject H0 | the effect is real, with size d). It increases with effect size, sample size, and α (looser threshold). Conventional target: 80% (90–95% for strong tests). Rules of thumb for a two-group t-test at α = .05, 80% power: d=.8 needs ~26 per group, d=.5 ~64, d=.2 ~394.

Underpowered studies: you miss real effects, and the ones that reach p<.05 are the ones that overestimated the effect (winner's curse). A literature that publishes only significant results then has inflated effect sizes. Pilots cannot fix this: with tiny N, the pilot's effect estimate is very imprecise (see the spread below). Better inputs: a meta-analysis, a smallest effect size of interest, or a general expectation ("what if it's medium?").

Sketch first: power (y, 0–1) vs N per group (x) for d = 0.2, 0.5, 0.8. Mark where each crosses 80%.

Challenges

  • d = 0.3, N = 20. Estimate power, then simulate. Compare the mean d̂ among significant results with the true d.
  • Set N = 10 and look at the grey+blue spread of d̂. If you ran a pilot like this, how far off could your effect-size estimate be?
  • Lower α to .005. What happens to the power curves? Why does the "significant" cut-off move right?

5. Estimates, effect sizes, and confidence intervals

Cohen's d = (mean difference) ÷ (pooled SD). It puts different scales on a common footing, but it also depends on how variable the sample is: the same raw difference gives a smaller d in a more variable population. Raw units are better when they're meaningful (ms, counts); d is better when scales are arbitrary.

Smaller studies, noisier estimates: the standard error is about σ/√n. Quadruple n to halve the SE.

95% CI: a procedure such that, over repeated studies, 95% of the intervals contain the true value. For one computed interval you can't say "95% probability the truth is inside". A CI that excludes 0 corresponds to p<.05, but the focus is on the range of plausible effect sizes.

6. Bayes factors

BF10 = P(data | H1) ÷ P(data | H0). It says how much better H1 predicted the data than H0 did.

  • BF10 = 3: data are 3× more likely under H1 than H0 (modest support for H1).
  • BF10 = 10: 10× (strong support for H1 by common conventions).
  • BF10 = 1/3: data are 3× more likely under H0 than H1. Equivalently BF01 = 3. Unlike p-values, BFs can support the null.

Versus p: p only considers the null and uses "data this extreme or more"; BF compares two specific models using the data actually observed. BF requires specifying H1 (here a default prior on effect size), is continuous (cutoffs like 3 or 10 are guidelines, not magic), and is independent of your prior odds: posterior odds = prior odds × BF. BFs can also be p-hacked if you selectively report.

Verbal labels (one common convention): 1–3 anecdotal, 3–10 moderate, 10–30 strong, 30–100 very strong, >100 extreme; mirror them below 1. Sources differ.

Try: n = 24 per group, t = 2.86 (p = .006): is the BF as extreme as the p suggests? Then n = 150, t = 2.0 (p≈.047). Notice that p<.05 can correspond to weak BF evidence.
